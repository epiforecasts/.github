# .github

This repository holds the organisation-wide files for the epiforecasts GitHub organisation. GitHub uses the files here as defaults for every epiforecasts repository that does not have its own copy, and shows the profile README on the organisation page.

- `profile/README.md`: the text on the epiforecasts organisation page, describing the group at the Centre for Mathematical Modelling of Infectious Diseases, London School of Hygiene & Tropical Medicine.
- `CODE_OF_CONDUCT.md`: the Contributor Covenant code of conduct, applied to any epiforecasts repository without its own.
- `REVIEW.md`: the general half of the code review specification, covering what to review (a PR, the commits since a given one, or the working diff), what counts as a finding, what to check before calling a change clean, and how to report. A repository can add its own `.github/REVIEW.md` with what to look for in that codebase, and a review then follows both.
